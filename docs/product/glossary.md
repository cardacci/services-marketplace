# Glossary

Use these terms consistently in docs, code and UI. Code uses the English term; UI uses the Spanish one.

| Term (code) | UI (es-AR) | Definition |
|---|---|---|
| User | Usuario | Any registered person. |
| Client | Cliente | A user acting as the one who requests a service. Replaces "tenant / inquilino" from early sketches, since owners need services too. |
| Professional | Profesional | A user with a professional profile who offers services. |
| Professional profile | Perfil profesional | Data that makes a user a professional: categories, availability, license, base location, rating. |
| Category | Rubro / Categoría | Type of service (plumber, gas fitter…). |
| License | Matrícula | Professional registration number; required for some categories. |
| Property | Dirección | An address of a client where a job takes place. Called "property" in the data model. |
| Availability rule | Horario | A time range on a weekday when a professional works. |
| Appointment | Cita / Turno | A service request from a client to a professional for a date and time. |
| Conversation | Chat | Message thread tied to one appointment. |
| Review | Valoración | Stars, comment and images left by one participant about the other after a completed appointment. |
| Reviewer / Reviewee | — | The user who writes a review / the user being reviewed. |
| Favorite | Favorito | A professional saved by a client. |
| Notification | Notificación | In-app message about an event (appointment accepted, new message…). |
